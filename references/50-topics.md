# 50 · 운영 주제

## 운영 주제 예시 (조 주제가 없을 때 선택지로)

| 영역 | 도구 예 | 핵심 흐름 한 줄 |
|---|---|---|
| 직원·급여 | 알바 주급 계산표 | 출퇴근 입력 → 휴게·주휴 계산 → 직원별 주급 표 |
| 근무 | 근무표·교대표 | 가능 시간 입력 → 주간 근무표 → 빈 시간 표시 |
| 교육 | 직원 매뉴얼 온라인 북 | 매뉴얼 등록 → 직원 검색·확인 → 안 본 사람 표시 |
| 루틴 | 오픈·마감 체크리스트 | 항목 체크 → 누가 언제 했는지 기록 → 빠진 항목 표시 |
| 원가 | 메뉴 원가 계산기 | 재료 단가·사용량 입력 → 메뉴별 원가율 → 가격 점검 |
| 재고 | 재료 재고·발주표 | 사용량·입고 입력 → 남은 양 → 발주 필요 표시 |
| 정산 | 월말 손익표 | 매출·비용 입력(파일 올리기) → 항목별 합계 → 순이익 |
| 매출 | 매출 분석 대시보드 | 매출 기록 입력(파일) → 기간·메뉴별 그래프 → 잘 팔린/안 팔린 것 |
| 준비 | 날씨 기반 준비량 | 날씨·요일 입력 → 지난 기록과 비교 → 준비량 추천 |
| 응대 | 손님 응대 연습·안내 | 상황 고르기 → 모범 응대 보기·연습 → 기록 |
| 채용 | AI 면접 질문지 | 직무 고르기 → 질문·평가표 → 면접 메모 저장 |
| 창업 | 창업 준비 체크리스트 | 단계별 항목 → 진행 체크 → 남은 일·비용 합계 |

v1에서 외부 연결(배민 데이터·날씨·카톡)은 **직접 입력이나 파일 올리기로 대신**하고, 자동 연결은 v2로 둔다.

## 이어 주기 — 운영이 아닌 주제를 운영 도구로

| 사장님이 말한 것 | 이어지는 운영 도구 (선택지) |
|---|---|
| 인스타 캐러셀·콘텐츠 | ① 메뉴별 판매·반응 기록표 (콘텐츠 소재가 숫자로 나옴) ② 콘텐츠 발행 일정·체크표 ③ 손님 질문 모음 → 응대 안내서 |
| 신메뉴·선물세트 기획 | ① 선물세트 주문 접수·생산 계획표 ② 신메뉴 원가·가격 계산기 ③ 시즌 준비 체크리스트 |
| 강의·교육 콘텐츠 | ① 창업 준비 체크리스트 도구 ② 내 가게 운영 매뉴얼 북 ③ 손익 점검표 |
| 리뷰 답글 | ① 리뷰 모아 보기·답글 초안 (스타터 키트: github.com/selfishclub/review-onetouch-starter) ② 리뷰 불만 유형 집계표 |
| 마케팅 분석 | ① 매출 분석 대시보드 ② 쿠폰·이벤트 효과 기록표 |
| 예약·주문 받기 페이지 | ① 예약·주문 접수 관리표 (받은 뒤 처리 흐름) ② 단체 주문 준비 체크리스트 |

선택지를 줄 때는 **사장님 가게 이름과 원래 아이디어를 넣어** 말한다.
예: "대게·킹크랩 캐러셀 대신, 해모닉에서 대게와 킹크랩이 어떤 날 얼마나 팔리는지 보는 대시보드를 만들면, 그 숫자가 나중에 캐러셀 재료가 돼요."
