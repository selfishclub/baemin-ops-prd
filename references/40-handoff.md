# 40 · 마무리와 넘기기

## 1. 저장 (캠프 저장소)

1. `git status`로 **내 폴더 안 파일만** 바뀌었는지 본다. 다른 폴더가 바뀌었으면 그 파일은 올리지 않고 사장님께 알린다.
2. `git diff --cached`로 실명·연락처·키·비밀번호가 없는지 본다.
3. 커밋 메시지: 모드 ① `전체 PRD·v1/v2 PRD 작성 (가게이름)` · 모드 ② `전체 PRD 채우고 v1/v2 나눔 (가게이름)` · 모드 ③ `v2 PRD 고도화: 사용메모 반영 (가게이름)`
4. `git pull --rebase` 후 `git push`. 내 폴더만 바뀐 확실한 작업이라 push까지 한다. 충돌이 나면 멈추고 알린다. 강제로 올리지 않는다.
5. "GitHub 웹에서 내 폴더를 열어 보시면 올라가 있어요"라고 확인시킨다.

일반 모드에서 git 저장소가 아니면 커밋 없이 파일 위치만 알려 준다.

## 2. v1 구현으로 넘기기 (모드 ①② 끝)

사장님께 아래 프롬프트를 복사해 쓰라고 보여 준다. 구현은 **사장님 개인 저장소(새 폴더)**에서 한다. 캠프 저장소에 코드를 넣지 않는다.

```
캠프 저장소의 [내 폴더]/v1/PRD.md 를 읽고 v1 범위만 만들어 줘.
새 폴더 ~/[도구-이름] 에서 시작하고, 내 GitHub에 Public 저장소로 올려 줘.
화면은 폰에서도 잘 보이게, 시연용 가짜 데이터로.
만들기 전에 화면 구성을 글로 먼저 보여 줘.
데이터 저장이 필요하면 Supabase를 쓰는데, 아래처럼 나눠서 해 줘:
- 네가 Claude in Chrome으로: 새 프로젝트(서울 지역, 비밀번호는 Generate 버튼), 테이블 만들기, RLS 잠금, 열쇠 화면(Project Settings → API) 열어 두기
- 내가 직접: Supabase 가입·로그인, 열쇠(Project URL, anon 키)를 .env.local과 Vercel 환경변수 칸에 붙여넣기
내 차례가 오면 멈추고 무엇을 어디에 하면 되는지 알려 줘. 열쇠 값을 채팅에 적거나 대신 입력하지 마.
.env.local 은 이름만 적어서 텍스트 편집기로 열어 줘. service_role 키는 쓰지 마.
```

### Supabase 단계에서 사장님께 가이드를 줄 때

가이드는 **사장님 차례가 오는 순간에만** 짧게 준다. 미리 길게 설명하지 않는다.

| 순간 | 한두 줄 가이드 |
|---|---|
| 가입·로그인 직전 | "크롬에 Supabase를 열어 뒀어요. **Continue with GitHub** → **Authorize** 누르시고 '로그인했어'라고 말해 주세요." |
| 크롬 확장 권한 창 | "Claude가 이 사이트를 다뤄도 되는지 묻는 창이에요. **허용**을 눌러 주세요." |
| 열쇠 붙여넣기 | "크롬 열쇠 화면에서 Project URL 복사 → 편집기 첫 줄 `=` 뒤에, anon public 복사 → 둘째 줄 `=` 뒤에. 저장(⌘S) 후 '저장했어'라고 말해 주세요. service_role은 복사하지 않아요." |
| Vercel 환경변수 | "환경변수 칸을 열어 뒀어요. 이름은 적어 뒀으니 값 칸에 같은 두 열쇠를 붙여넣어 주세요." |
| 막혔을 때 | 오류 문구를 그대로 받아 원인 한 줄 + 다음 행동 한 줄. 두 번 실패하면 "운영진을 불러 주세요." |

캠프 저장소에 `03_인터넷에서_접근가능하게_만들기/2_Supabase_데이터창고연결.md`가 있으면 그 문서를 함께 알려 준다.

### 캠프 밖(일반 모드)일 때 프롬프트에서 바꿀 곳

- 첫 줄: `[기획 폴더]/v1/PRD.md 를 읽고 v1 범위만 만들어 줘.`
- 저장소 공개 여부: 캠프는 Public이 제출 요건이다. 캠프 밖이면 사장님께 묻고(기본 추천: 비공개), 그 답으로 `Public`/`비공개`를 바꾼다. 어느 쪽이든 `.env*`는 올리지 않는다.
