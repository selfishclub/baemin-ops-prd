# 30 · v2 고도화 (모드 ③)

v1을 만들어 써 본 뒤, 쓴 기록으로 v2를 고친다. **v2가 처음 초안과 달라지는 게 정상이다.**

## 읽을 것 (AI 혼자)

`PRD_전체.md` · `v1/PRD.md` · `v1/사용메모.md` · `v1/제출서.md`(있으면) · `중간점검_1002.md`(캠프, 없으면 `_양식/중간점검_1002.md`에서 만든다) 또는 `중간점검.md`(일반 모드, 없으면 `templates/`에서 만든다) · `v2/PRD.md`

**PRD_전체가 빈 양식이면** 질문 없이 v1 PRD로 먼저 채운다. 꼬리표는 [v1] = v1 5번 기능, [v2] = v1 7번, 그 밖의 "하지 않을 것"은 `20-split.md` 기준으로 [v2]/[나중]을 정한다(예: 직원 로그인 = [v2] 기준에 해당). 채운 결과는 인터뷰 전에 한 번 보여 주고 틀린 곳만 고친다(블록별 질문은 하지 않는다). 9번 "지금" 숫자가 없으면 인터뷰 6번에서 "전에는"으로 받는다.

사용메모가 비어 있으면 먼저 말로 받는다: "v1을 몇 번, 누가, 언제 써 보셨어요? 기억나는 장면 하나만요." 받은 내용은 사용메모에 한 줄씩 적는다(사장님 확인 후).

## 인터뷰 — 최대 30분(첫 질문부터), 한 번에 한 질문

시작할 때 "30분 안에 끝낼게요"라고 말한다.

1. **쓴 횟수와 사람** — 몇 번, 누가 (사장님만 / 직원도)
2. **제일 도움 된 것** — 하나
3. **불편·막힌 것** — 사용메모의 각 줄을 짚으며 "그때 왜 그랬어요?"
4. **결국 손으로 한 일** — "도구를 두고 카톡·종이·엑셀로 한 게 있어요?" ← v2의 가장 좋은 재료
5. **안 쓰게 된 기능** — 이유
6. **줄어든 것** — 전: 전체 PRD 9번의 "지금" / 후: 지금. 재 본 숫자인지 어림인지 표시

짧은 답 처리는 `10-interview.md` 「파고들기」와 같다.

## 사용 기록 → 변경안

각 기록을 넷 중 하나로 나눠 표로 보여 주고 **확인받는다**(첫 번째 확인).

모드 ③의 확인은 이 **두 번**이다(분류표 · 변경안). 미리 채운 전체 PRD와 사용메모에 옮겨 적는 줄은 확인이라기보다 "틀린 곳 있으면 말씀해 주세요"로 보여 주기만 한다.

| 종류 | 예 | 가는 곳 |
|---|---|---|
| v1 버그·손볼 곳 | 검색이 띄어쓰기를 못 찾음, 사진 업로드 느림 | v1 보완 (v2 기능으로 세지 않음) |
| 새 기능 / 바꿀 기능 | 새 버전을 누가 봤는지 알고 싶다 | v2 변경안 **추가·바꿈** |
| 필요 없어진 것 | 퀴즈는 안 쓸 듯 | 원래 [v2]였으면 변경안 **뺌**, 원래 [나중]이면 전체 PRD 12번에만 기록 |
| 확인 필요 | 카톡으로 또 물어봄 (화면이 안 보여서? 전하려고?) | 인터뷰 답을 듣고 위 셋 중 하나로 옮긴다 |

처음 계획한 [v2] 기능은 기록으로 **근거를 확인**한다. 근거가 있으면 유지하고, 없으면 "써 보니 필요 없음"으로 내린다. 준비 기간이 긴 연결(카톡 알림톡 심사 등)은 "꼭 할 것"에 **API 없이 되는 절반**(안내문 만들기 + 복사 버튼)을 두고, 자동 발송은 "여유 있으면"으로 둔다.

## 파일 고치기 (순서대로)

변경안(추가/뺌/바꿈 + v2 꼭 할 것)을 먼저 채팅으로 보여 주고 **두 번째 확인**을 받은 뒤 파일을 고친다.

1. `중간점검_1002.md` — 1~3번은 기록에서, 4번에 막힌 것 + **v1 보완 목록**, 5번 변경안 표(추가/뺌/바꿈 + **이유는 사용메모의 날짜와 내용**), 6번 v2 범위(꼭 할 것 / 여유 있으면 / 이번엔 안 할 것 / 준비물).
2. `PRD_전체.md` — 4번 꼬리표를 변경안대로 바꾸고, 12번 변경 기록에 **날짜 · 무엇 · 왜(어느 기록 때문에)**를 한 줄씩.
3. `v2/PRD.md` — 변경안을 반영해 채운다. 초안 표시는 `20-split.md` 「v2 초안 표시」 표대로(오늘 날짜로 점검 전·후를 판단).
4. v1 보완은 고치는 일을 사장님 개인 저장소에서 따로 한다고 안내하고, 다음에 부를 말을 준다: "v1 보완 목록대로 고쳐 줘".

## 확정 전 확인

- v2 "꼭 할 것"이 10/17까지(또는 사장님이 정한 기한까지) 가능한 양인가
- 외부 연결마다 준비물과 걸리는 기간을 적었나
- 8번 자동화 금지가 v2의 새 기능에도 맞나 (예: 알림 보내기 버튼은 사람이)
