# 00 · 상태 판별

`scripts/detect.sh "<절대 경로>"`는 아래를 출력한다. 결과를 사장님께 쉬운 말로 보여 주고, 모드가 확실하면 알리고 애매하면 추천을 첫 선택지로 묻는다(SKILL.md 「시작할 때」 4).

## 1. 어디서 일하나

| detect.sh 결과 | 뜻 | 할 일 |
|---|---|---|
| `CAMP <경로>` | 배민 실전 캠프 저장소(`02_실전캠프_*_실습제출/` 있음) | 캠프 모드. 폴더 안 `_양식/`을 쓴다 |
| `NO_CAMP` | 캠프 저장소가 아님 (배민아카데미 다른 사장님 등) | 일반 모드. 아래 「일반 모드」 |

캠프 저장소가 홈 폴더 아래 다른 곳에 있을 수 있다. `NO_CAMP`인데 사장님이 캠프 참가자라고 하면 `find ~ -maxdepth 4 -type d -name '02_실전캠프*' 2>/dev/null`로 한 번 찾는다.

## 2. 내 폴더 찾기 (캠프 모드)

- `MINE <폴더>`가 출력되면 그 폴더가 사장님 폴더다. 확인만 한다.
- 아니면 폴더 이름 형식 `N조_이름_가게`에서 사장님 이름이나 가게 이름이 들어간 폴더를 고른다.
- 여러 개가 맞거나 하나도 없으면 목록을 보여 주고 묻는다.
- **내 폴더 밖은 읽기만 한다.** 같은 조 PRD는 참고용으로 읽어도 된다.

## 3. 파일 상태 (detect.sh 폴더 단위 출력)

각 파일을 양식과 비교해 셋 중 하나로 표시한다.

| 표시 | 기준 |
|---|---|
| `빈양식` | 양식에 없는 줄이 6줄 이하 (이름·조 주제·제목 줄만 채워진 상태) |
| `일부` | 양식에 없는 줄이 7~15줄 |
| `작성됨` | 16줄 이상 |

`사용메모.md`는 `기록 N·메모 M`으로 표시한다. 기록 = 예시 줄(9/17 시연) 말고 날짜로 시작하는 표 줄, 메모 = 「떠오른 것」·「반응」에 적힌 줄. `중간점검*.md`는 위와 같은 양식 비교다.

## 4. 모드 추천

위에서부터 먼저 맞는 것.

| 조건 | 추천 |
|---|---|
| v1을 만들어 써 본 근거: 사장님이 "써 봤다 / 중간 점검 준비"라고 함, 또는 사용메모 기록·메모 1개 이상, 또는 중간점검 `일부` 이상 (**"v2"라는 말만으로는 해당 안 됨**) | ③ v2 고도화 |
| v1/PRD.md `일부`·`작성됨`, 또는 사장님이 기존 기획안·아티팩트 링크를 줌 | ② 이어 쓰기 |
| 그 외 | ① 처음 쓰기 |

③인데 PRD_전체.md가 `빈양식`이면: 먼저 v1 PRD로 전체를 채우고(모드 ②의 미리 채우기, 질문 없이), 12번 첫 줄에 "(날짜) v1 PRD에서 옮겨 처음 작성"이라고 적은 뒤 ③을 진행한다.

## 5. 일반 모드 (캠프 저장소가 아닐 때)

1. 저장할 폴더를 묻는다. 선택지: 지금 폴더 (추천) / 새 폴더 `~/baemin-ops-prd-기획`
2. 그 폴더에 `templates/`의 파일로 아래 구조를 만든다. `중간점검.md`는 모드 ③에서 처음 만든다.
   ```
   PRD_전체.md
   v1/PRD.md · v1/사용메모.md
   v2/PRD.md
   ```
3. git 저장소면 캠프와 같이 커밋한다. 아니면 "파일로만 남아요"라고 알리고 커밋하지 않는다. (사용메모 양식의 "커밋·push" 문구도 git 저장소일 때만 해당한다고 알린다.)
4. 조 주제가 없으니 주제 고르기는 `50-topics.md` 「운영 주제 예시」로 한다.
