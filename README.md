# 배민 옵스 PRD (baemin-ops-prd)

**가게 운영 도구를 바이브 코딩으로 만들기 전에, Claude와 인터뷰하며 기획안(PRD)을 쓰는 스킬**입니다.
배민 실전 캠프와 배민아카데미 사장님을 위해 만들었습니다.

- 짧게 답해도 Claude가 예시를 들며 한 번 더 여쭤봅니다. 기획이 단답형으로 끝나지 않게요.
- **전체 그림을 먼저** 그리고, 오늘 만들 **v1**과 써 본 뒤 더할 **v2**로 나눕니다.
- v1을 써 본 뒤 다시 부르면, 쓴 기록으로 **v2를 다듬어** 줍니다.
- 인터뷰는 **최대 30분**입니다.

```
전체 PRD ──나누기──▶ v1 PRD ──만들기──▶ v1 써 보기(사용메모) ──▶ 중간 점검 ──▶ v2 PRD 고치기 ──▶ v2 만들기
            └──────▶ v2 PRD (초안) ────────────────────────────────────────┘
```

## 설치 — Claude에게 이렇게 말하세요

Claude Code(Claude 데스크톱 앱의 Code 탭 포함)에 그대로 붙여넣습니다.

> 이 스킬 쓰고 싶어: https://github.com/selfishclub/baemin-ops-prd
> `~/.claude/skills/baemin-ops-prd` 에 받아서 적용해 줘. 이미 있으면 최신으로 업데이트해 줘.

Claude가 하는 일 (직접 하실 필요 없음):

```bash
git clone https://github.com/selfishclub/baemin-ops-prd ~/.claude/skills/baemin-ops-prd
```

이미 있으면 `git -C ~/.claude/skills/baemin-ops-prd pull`. 설치 뒤 스킬이 안 보이면 **새 대화**를 열어 주세요.
스킬은 쓸 때마다 스스로 최신 버전을 받아 옵니다.

## 쓰는 법

| 상황 | 이렇게 말하세요 |
|---|---|
| 처음 기획 | "배민 옵스 PRD로 기획안 써 줘. 나는 [치킨집]인데 [재고 떨어지는 거]가 힘들어." |
| 사전 과제 PRD가 있을 때 | "배민 옵스 PRD로 이 기획안 이어서 써 줘. [붙여넣기 또는 아티팩트 링크]" |
| v1을 써 본 뒤 | "v1 써 봤어. 배민 옵스 PRD로 v2 다듬자." |
| 중간 점검 전 | "중간 점검 준비하자. 사용메모 보고 채워 줘." |

## 만들어지는 파일

| 파일 | 내용 |
|---|---|
| `PRD_전체.md` | 다 만들었을 때의 모습. 기능마다 [v1] / [v2] / [나중] 꼬리표 |
| `v1/PRD.md` | 오늘 만들 것 |
| `v2/PRD.md` | 써 본 뒤 더할 것 (처음엔 초안) |
| `v1/사용메모.md` | v1을 쓸 때마다 한 줄 |
| `중간점검.md` | 사용메모를 모아 v2 변경안 정리 |

**배민 실전 캠프 참가자**는 캠프 저장소(`baemin-ops-os-camp`)의 내 폴더에 저장되고, 내 폴더만 커밋·push됩니다.
**그 밖의 사장님**은 원하는 폴더에 저장됩니다.

## 지키는 것

- 기획까지만 합니다. 코드는 끝에 넘겨 드리는 프롬프트로 따로 만듭니다.
- 실제 직원·손님 이름, 연락처, 매출 파일, 비밀번호·API 키는 적지 않습니다.
- Supabase를 쓸 때 **가입·로그인과 열쇠 붙여넣기는 사장님이 직접**, 나머지는 Claude가 크롬에서(Claude in Chrome) 대신합니다.
- 급여 확정·메시지 보내기·결제 같은 버튼은 사람이 누르도록 기획합니다.
